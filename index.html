Studio

A private tool for one YouTube channel.

Studio helps its owner, Vector, make and publish short videos (YouTube Shorts) on his own channel. It is a personal tool, not a public service: only the channel owner signs in to it.

With the owner's permission, Studio uses the YouTube Data API and YouTube Analytics API to:

  • look up publicly trending Shorts, to suggest video ideas;
  • upload a video to the owner's channel, only after the owner approves that specific video;
  • read the channel's video statistics, to report back to the owner how each video is doing.

Studio does not access any other channel's private data, and does not edit or delete existing videos.
